# تپه‌نورد (Hill Hop Horizon)

یک بازی مسابقه‌ای فیزیک‌محور دو بعدی با الهام از Hill Climb Racing 2.

## مشخصات بازی
- فیزیک واقعی خودرو، تعلیق و شیب تپه‌ها
- پدال‌های گاز و ترمز
- باک سوخت و مصرف بنزین
- جمع‌آوری سکه و ارتقای خودرو
- سازگار با موبایل و کامپیوتر
